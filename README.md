# ⚡ 전력 수급 모니터

서울 기준 날씨와 전국 전력 데이터를 결합해 **과거 전력 수급 현황**과 **미래 예비력 경보**를 한 화면에서 보여주는 Streamlit 대시보드입니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 현재 수급 현황 | KPX API 실시간 공급능력 · 수요 · 예비력 · 예비율 |
| 과거 30일 추이 | 일별 최대수요 · 예비력 · 경보 등급 색상 마커 |
| 기온/습도 오버레이 | 전력 수요와 날씨 상관관계 시각화 |
| 경보 발령 이력 | 관심 이상 경보 날짜 테이블 |
| 시간별 발전량 | 날짜 선택 → 24시간 발전원별 스택 차트 |
| 예비력 예측 | 기온·습도·시간대·요일 입력 → 24시간 예비율 예측 + 경보 |
| 기상청 예보 연동 | 예보 시각 선택 시 날씨 조건 자동 입력 |
| 유사 과거 비교 | 입력 날씨와 유사한 과거 데이터 자동 검색 |

## 사용 API

| API | 출처 | 갱신 |
|-----|------|------|
| 기상청 단기예보 조회서비스 | apis.data.go.kr | 1시간 캐시 |
| 한국전력거래소_현재전력수급현황 | openapi.kpx.or.kr | 5분 캐시 |

> ⚠️ **한국전력거래소_시간별 발전량** API는 현재 심의 중입니다.  
> 승인 후 `app.py`의 `make_hourly()` 함수에 실제 API 호출 코드를 추가하세요.

## Streamlit Cloud 배포 방법

### 1단계 — GitHub 저장소 준비

```
power_monitor/
├── app.py
├── requirements.txt
└── .streamlit/
    └── secrets.toml   ← 로컬 테스트용 (GitHub에 올리지 마세요!)
```

`.gitignore`에 반드시 추가:
```
.streamlit/secrets.toml
```

### 2단계 — Streamlit Cloud 배포

1. [share.streamlit.io](https://share.streamlit.io) 접속 → GitHub 로그인
2. **New app** → 저장소 · 브랜치 · `app.py` 선택
3. **Advanced settings → Secrets** 항목에 아래 내용 입력:

```toml
api_key = "dc4386cd56458b5e4c304d0175fccf6b35fe8b201c18496e29643a4531d62df7"
```

4. **Deploy!** 클릭

### 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 경보 기준

| 단계 | 예비율 | 의미 |
|------|--------|------|
| ✅ 안전 | ≥ 15% | 정상 운영 |
| 🔵 관심 | 10–15% | 모니터링 강화 |
| ⚠️ 주의 | 7–10% | 수요 관리 권고 |
| 🔶 경계 | 5–7% | 비상 절전 준비 |
| 🚨 심각 | < 5% | 비상 절전 시행 |

> 예측 모델은 교육 목적의 단순화된 추정치이며 실제 계통 운영과 다를 수 있습니다.
